# Pier Map

The Pier map owns the three exterior levels:

- `pier-start`
- `pier-middle`
- `pier-end`

It also owns the horizontal connection graph between those levels.

This folder also owns the current concrete level implementations and the Pier-only assets and
helpers used by those screens.

`src/cartridges/rocco/levels/pier/**` remains as a compatibility wrapper over this folder.
