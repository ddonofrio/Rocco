# Terminal Work In Progress

This cartridge is an archived internal reference for the plane and effect systems.

Do not use Terminal as the template for new cartridges. Use `rocco-default` as the working reference cartridge.

## Role

- Loads a minimal plane scene with a procedural star field.
- Registers and activates `auto-scroll` on the star plane.
- Places a default sprite in the scene.

## Files

- `terminal-work-in-progress-cartridge.ts` - Main cartridge class.
- `terminal-work-in-progress-manifest.ts` - Manifest for `terminal-work-in-progress`.
- `terminal-work-in-progress-scene.ts` - Scene creation.
- `terminal-work-in-progress-effects.ts` - Auto-scroll setup.
- `terminal-work-in-progress-sprites.ts` - Default sprite installation.
- `terminal-work-in-progress-sprite-definition.ts` - Sprite definition.
- `terminal-work-in-progress-constants.ts` - Constants.
- `terminal-work-in-progress-compatibility.ts` - Compatibility helpers.
