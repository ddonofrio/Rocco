# Titles

The titles subsystem renders free-positioned text overlays such as hover descriptions, temporary labels, and short scene annotations. It is a simple console-owned text layer above the scene.

## Files

- `types.ts` - Title style, title message, and title SDK contract types.
- `system.ts` - `RoccoTitleSystemSDK`, the pure SDK state for title registration, lookup, removal, and TTL expiry.
- `pixi-renderer.ts` - PixiJS renderer for positioned overlay text and anchor handling.
- `index.ts` - Barrel export.

## Behavior

- A title has a stable `id`, `text`, `renderLayer`, `zIndex`, absolute scene-space position, and `visible` flag.
- Optional `anchor` and `style` fields control text alignment and visual styling.
- Optional `ttlMs` makes a title self-expire during `update(deltaMs)`.
- Titles without `ttlMs` remain until the runtime or cartridge removes them explicitly.

## Boundary

Cartridges use `engine.video.titles` when they need a short overlay that is not anchored to a sprite bubble. The runtime also uses the same subsystem for hover descriptions generated by `RoccoInputHandler`. Cartridges provide text and placement; the console owns overlay state, update timing, and Pixi text rendering.
