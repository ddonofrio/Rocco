# Graphic Planes

Graphic planes provide layered backgrounds and visual scene composition.

## Files

- `types.ts` - Plane, scene, source, color model, palette, and attribute-map types.
- `sdk.ts` - `RoccoGraphicPlaneSDK`, pure scene and plane state logic.
- `scene-factory.ts` - Starter scene factory.
- `wrap.ts` - Modular scroll wrapping helper.
- `renderer.ts` - Plane renderer contract.
- `pixi-renderer.ts` - PixiJS plane renderer, source handling, viewport masking, tiling, and water animation.
- `index.ts` - Barrel export.

## Plane Source Types

| Kind         | Description                                      |
| ------------ | ------------------------------------------------ |
| `solid`      | Solid color rectangle                            |
| `image`      | Static image URI with optional water animation   |
| `bitmap`     | Raw indexed or RGBA pixel data                   |
| `tileset`    | Tile sheet definition                            |
| `tilemap`    | Grid of tile references                          |
| `procedural` | Generated by a registered procedural generator   |

## Color Models

| Kind              | Description                              |
| ----------------- | ---------------------------------------- |
| `native`          | Use colors as provided                   |
| `indexed`         | Map pixel indices through a palette      |
| `palette-remap`   | Swap one palette for another             |
| `color-registers` | Substitute named color registers         |
| `tint`            | Apply tint with a configurable strength  |

## Water Color Effect

Image planes can declare `metadata.waterColorEffect`. The Pixi renderer splits selected water-colored pixels into an animated water layer, keeps non-water pixels static, and clips animation back to the selected mask.

Water tuning and color-key behavior live in `src/engine/video/post-processing/README.md`.

## Procedural Generators

The built-in `star-field` generator is registered in `GameRuntime`. Additional generators implement `RoccoProceduralGenerator` and are registered with the plane SDK runtime setup.
